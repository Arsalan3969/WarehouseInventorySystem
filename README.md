# Warehouse Inventory Management System

A Java Swing + MySQL desktop application developed for managing warehouse operations.

## Features

- User Login & Role-Based Access
- Dashboard
- Product Management
- Supplier Management
- Customer Management
- Warehouse Management
- Purchase Orders
- Purchase Order Items
- Goods Receipt
- Sales Orders
- Sales Order Items
- Inventory Transactions
- Reports

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA
- Git & GitHub
