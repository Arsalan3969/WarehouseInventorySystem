# 📦 Warehouse Inventory Management System

A desktop-based Warehouse Inventory Management System developed using **Java Swing**, **JDBC**, and **MySQL**. The application provides an efficient way to manage warehouse operations, including inventory, suppliers, customers, purchase orders, sales orders, and goods receipts through a user-friendly graphical interface.

## ✨ Features

* 🔐 Secure Login System
* 👤 Role-Based Access Control
* 📦 Product Management
* 🏢 Supplier Management
* 👥 Customer Management
* 🏬 Warehouse Management
* 🛒 Purchase Order Management
* 📥 Goods Receipt Management
* 💰 Sales Order Management
* 📊 Inventory Transaction Tracking
* 📈 Reports Dashboard
* 🗄️ MySQL Database Integration

## 🚀 Getting Started

### Prerequisites

* Java JDK 25 or later
* MySQL Server
* IntelliJ IDEA
* Maven

### Installation

1. Clone the repository

```bash
git clone https://github.com/Arsalan3969/WarehouseInventorySystem.git
```

2. Open the project in IntelliJ IDEA.

3. Create a MySQL database.

```sql
CREATE DATABASE WarehouseInventorySystem;
```

4. Import the SQL file located in the `database` folder.

5. Update your database credentials in `DBConnection.java`.

6. Run `Main.java`.
